# Infinity Tunnel

Android DNSTT (SlowDNS) client: editable server config, SSH tunnel and VPN mode.

- DNSTT server name + public key
- Resolver choice (1.1.1.1 / 8.8.8.8 / custom)
- SSH host, port, username, password
- UDPGW + SOCKS ports, MTU
- One-tap connect with live logs

Builds run on GitHub Actions (`.github/workflows/build.yml`) — download the
`InfinityTunnel-debug` artifact for the APK.
